# Quadrotor Model

Shared by every stage: `quadrotor_3d_model.py`. One dynamics builder produces all model
variants (nominal, disturbance-parameterized, augmented), so every stage uses exactly the
same physics.

## States, inputs, conventions

| Property | Value |
|----------|-------|
| States $x$ (13) | $[p_x\; p_y\; p_z,\; v_x\; v_y\; v_z,\; q_w\; q_x\; q_y\; q_z,\; p\; q\; r]$ |
| Inputs $u$ (4) | $[f_1\; f_2\; f_3\; f_4]$, individual motor thrusts [N] |
| Frames | position and linear velocity in the world frame; angular rates $p\; q\; r$ in the body frame |
| Attitude | unit quaternion, scalar-first, body → world, `+` motor layout |
| Hover | $q = [1, 0, 0, 0]$, $f_{\text{hover}} = mg/4 \approx 2.45$ N |
| Input bounds | $0 \le f_i \le f_{\max} = 3 f_{\text{hover}} \approx 7.35$ N |
| Integration | ERK4 (acados) |

> Naming: $q$ in $[p\; q\; r]$ is the body pitch rate, not to be confused with the quaternion
> components $q_w, q_x, q_y, q_z$.

Motor thrust is used directly as the control input. This is valid in simulation because the
motor dynamics are much faster than the MPC loop.

## Equations of motion

**Translational dynamics** (world frame). Thrust acts along the body $z$-axis, so only the third
column of the rotation matrix $R(q)$ is needed:

$$\dot{p} = v, \qquad
\dot{v} = \frac{f_{\text{total}}}{m}\, R(q)_{:,2} - g\, e_z, \qquad
f_{\text{total}} = f_1 + f_2 + f_3 + f_4 .$$

**Rotational kinematics** (quaternion, scalar-first):

$$\begin{aligned}
\dot{q}_w &= -\tfrac12\,(q_x p + q_y q + q_z r) \\
\dot{q}_x &= \phantom{-}\tfrac12\,(q_w p + q_y r - q_z q) \\
\dot{q}_y &= \phantom{-}\tfrac12\,(q_w q - q_x r + q_z p) \\
\dot{q}_z &= \phantom{-}\tfrac12\,(q_w r + q_x q - q_y p)
\end{aligned}$$

equivalently $\dot{q} = \tfrac12\, q \otimes [0, p, q, r]$.

**Rotational dynamics** (rigid-body Euler equations, body frame, independent of the attitude
representation):

$$I \dot{\omega} = \tau - \omega \times (I \omega), \qquad \omega = [p, q, r],$$

with the torques generated by differential thrust

$$\tau_x = L(f_4 - f_2), \qquad \tau_y = L(f_3 - f_1), \qquad \tau_z = c_\tau(-f_1 + f_2 - f_3 + f_4).$$

$L$ is the arm length, $c_\tau$ the rotor drag-to-thrust coefficient and $I$ the diagonal inertia
tensor. Stacking the above gives the 13-state model $\dot{x} = f(x, u)$.

## Disturbance model (Stages 3–4)

A constant disturbance $d = [d_f;\, d_\tau] \in \mathbb{R}^6$ enters as a world-frame force and a
body-frame torque:

$$\dot{v} = \frac{f_{\text{total}}}{m}\, R(q)_{:,2} - g\, e_z + \frac{d_f}{m}, \qquad
I \dot{\omega} = \tau - \omega \times (I\omega) + d_\tau .$$

| Variant | Role of $d$ | Used by |
|---|---|---|
| nominal | $d = 0$ | Stages 1–2 |
| disturbance-parameterized | runtime parameter `model.p` | MPC ($p = \hat d$) and plant ($p = d_{\text{true}}$) |
| augmented | extra states, $\dot d = 0$, $z = [x;\, d] \in \mathbb{R}^{19}$ | EKF and MHE |

## Quaternion details

- **Cost weights.** For small angles $\phi \approx 2 q_x$, $\theta \approx 2 q_y$, $\psi \approx 2 q_z$, so quaternion
  weights are set about $4\times$ the equivalent Euler-angle weights. $q_w$ is only lightly weighted,
  since it is not independent of the vector part.
- **Norm drift.** The plant state passes through `quat_normalize(x)` after every step,
  which also enforces the $q_w > 0$ hemisphere.
- **Linearization.** At hover, $q_w$ is an uncontrollable marginal mode of the linearized model,
  so Riccati-based computations (CARE, DARE) use the 12-state model without $q_w$ and re-insert
  it afterwards with its weight from $Q$.
